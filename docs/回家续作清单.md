- ReAct Agent 的读工具、结构化写入、幂等与边界校验；

- 未闭环故障只保存 chain state，不进入正式记忆召回；
- 修复被否定时，同一链从 `fix_applied` 进入 `fix_rejected`，保留失败尝试历史；
- 编译验证必须对应原始失败步骤，不能用上游编译成功替代烧录/下载验证；
- `memory_multiturn_v1` 前 9 个真实场景共 26 个 turn 全部通过。

本次已经实现、但尚未完成真实 LLM 发布门禁验收：

- 一个 turn 可以通过 `chain_operations[]` 同时关闭旧故障链和创建独立的新故障链；
- 每个操作明确声明 `update_existing` 或 `create_new`；
- 正式技术 memory 通过 `linked_change_indexes` 精确绑定到对应闭环链；
- 新现象链不会误用旧链 ID，也不会继承旧链的最终 memory；
- 多操作中任一落库失败会返回 `partial_failure`，不会静默当作成功；

## 5. 安装与本地配置

### 5.1 拉取代码


### 5.2 Python

使用 Python 3.11+。如果没有 Codex bundled Python，设置：

```powershell

```

### 5.3 DeepSeek 密钥

在仓库根目录新建且不要提交：

```text

```

```json

  "deepseek_api_key": "填写有效密钥"
}
```

运行正式回放前先确认账号余额足够；当前最后一次失败原因就是 HTTP 402。

### 5.4 PostgreSQL

推荐继续使用：

```text
host=localhost
port=55513
database=codepulse_memory_lab
user=root
```

本地创建 `pg-memory-lab.local.json`，密码只写本机文件。可参考结构：

```json
{
  "schema_version": "memory-lab-postgres-config-v1",
  "postgres": {
    "host": "localhost",
    "port": 55513,
    "database": "codepulse_memory_lab",
    "user": "root",
    "password": "填写本机密码",
    "sslmode": "disable"
  },
  "user": {
    "user_id": "local-default-user",
    "email": ""
  }
}
```

恢复快照示例：

```powershell

pg_restore -h localhost -p 55513 -U root -d codepulse_memory_lab `
  .\codepulse_memory_lab.dump
```

如果数据库已存在且要保留，不要直接覆盖；先新建测试数据库或先备份。
